# Antigravity bridge 的差异与取舍

对照版本为 [NaghtSieger/dsh-antigravity-bridge 的 `4ad23a1`](https://github.com/NaghtSieger/dsh-antigravity-bridge/tree/4ad23a1fbe805af1a838a50d7b6646a110902ee4)。表中的工具与长会话实测使用 agy 1.5.15 和 Neon High。

## 建议保留的五处差异

| 项目 | 对方实现 | 本插件的做法与保留理由 |
| --- | --- | --- |
| 工具执行与审批 | 默认 `safe-bridge` 使用 agy 默认代理，通过会话参数禁用内置工具。 | 使用工具白名单为空的专用代理，通过 MCP 提供 DSH 工具。实测 agy 1.5.15 的默认代理收到空工具数组后仍能直接读文件，DSH 审批回调为零。专用代理下，Neon High 写测试文件时，DSH 拒绝后文件不存在，允许一次后写入内容正确。 |
| 官方系统提示与 DSH 规则 | 新增 `safe-bridge` 模式，在首次用户上下文中附上规则和工具签名。 | 沿用现有 `bridge` 模式。新建和恢复 agy 会话时均省略 `systemPrompt`，让 agy 按所选工具生成官方系统提示。DSH 规则随首次用户上下文传入，工具由 MCP 声明。现有预设能直接使用，真实会话已验证规则生效、工具可用、重启后可以续接。 |
| 长会话交接与消息顺序 | 超长时可把后面的上下文提前发送；图文和并行工具的补充消息在部分路径会集中发送。 | 大段正文可以提前分块传输，但在回答轮保留原位置引用；图片和每次工具结果后的补充说明保持原有顺序。这样模型能分辨哪条说明属于哪个结果。Neon High 切换模型后答出了 254,889 字节历史首尾的随机值，另一次位置测试也按预期顺序答出了三个随机值。 |
| 长工具结果 | 超限时保留首尾，提示模型缩小查询范围后再取。 | 支持分页读取同一次调用的原始结果。日志、进程输出等会随时间变化，重新执行无法保证得到原来的中段。实测从约 19 KB 的工具结果中取回了位于中段的唯一故障编号。 |
| 429 限流 | 对流中的 429、401、403 等信号使用范围较宽的熔断和错误分类。 | 第一次收到普通 429 就返回上游错误，保留可用的追踪编号和退避时间，不自动重试或切换账号。只有上游明确报告额度耗尽，才停用对应账号的模型组。模拟上游返回 429 时，实测 DSH 重试事件为零，包括工具结果晚于 429 到达的情况。 |

bridge 省略 `systemPrompt`，由 agy 根据专用代理的工具范围组织系统提示，因此其文本可以与默认 CLI 不同。DSH 工作区规则从用户上下文进入。

## 根据评审补齐的三项行为

| 项目 | 已采用的做法 | 验收依据 |
| --- | --- | --- |
| macOS / Linux 安装路径 | 保持显式指定的程序、原有安装目录和 `PATH` 的优先级。全部找不到时再查找平台常用位置。 | Windows 隔离测试使用临时目录模拟两种平台，覆盖同时存在多份 agy 及仅兜底目录存在两种情况。 |
| 子进程认证环境 | 启动 ACP 和辅助命令时清除四个继承变量，保留指定的 `HOME`。作用域为子进程。 | 在隔离 DSH SDK 中以虚拟值探测。宿主原先过滤了三个含 `KEY` 的变量，`AGY_ADC_AUTH` 会传给子进程；插件处理后四项均未传入。 |
| 流中的认证或条款错误 | 收到 agy 重试通知中的明确 401、403、`UNAUTHENTICATED`、`PERMISSION_DENIED` 或 `TOS_VIOLATION` 后，沿用现有取消通道，并保留上游消息和可用追踪编号。 | 模拟 ACP 测试覆盖分块、历史交接与正常回复；每次错误只有一次上游尝试和一次取消，普通回复提到状态码仍然可见。普通 429 沿用原处理。 |

回归用例见[上游错误处理](../tests/failover-classification.test.mjs)和[启动及工具测试](../tests/runtime.test.mjs)。
